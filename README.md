# Reel Studio

Локальная сборка вертикальных роликов в Codex или Claude Code. Откройте папку как проект. Агент напишет сценарий, подберёт графику и соберёт ролик. MP4 и редактируемый проект появятся в output/.

## Установка

Скопируйте текст из [ПРОМПТ-УСТАНОВКИ.txt](ПРОМПТ-УСТАНОВКИ.txt) в Codex или Claude Code. Агент скачает проект из [открытого репозитория](https://github.com/maratch01-debug/reel-studio-student), установит зависимости и соберёт три учебных ролика. Вход в GitHub не нужен.

Для самостоятельного запуска клонируйте репозиторий, перейдите в папку и запустите установщик.

    git clone https://github.com/maratch01-debug/reel-studio-student.git
    cd reel-studio-student

**Windows, PowerShell**

    powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Demo

**macOS, Терминал**

    sh install.sh --demo

На Windows для отсутствующих инструментов используется WinGet, на macOS — [Homebrew](https://brew.sh/). Добавьте -Voicebox на Windows или --voicebox на macOS, чтобы скачать и открыть официальный установщик Voicebox с проверкой SHA-256. Запустите приложение и выберите голос. Можно использовать готовый WAV.

Установщик сохраняет учебные MP4 в папках форматов внутри `2d-output/`. Рядом с каждым роликом лежит монтажный проект `project.json`.

## Первый ролик

> Сделай вертикальный рилс на белом фоне с тигрицей про прокат настольных игр. Придумай хук, покажи схему из трёх шагов, озвучь на русском и добавь фоновую музыку. Сохрани MP4 и монтажный проект.

В примерах есть пантера, тигрица и волк. В каждом формате можно использовать своего героя, свой голос и музыку.

## Форматы

| № | Формат | Подача |
| --- | --- | --- |
| 1 | Белый фон (`white-background`) | Чистый белый фон, говорящий герой, иллюстрации и короткие подписи. |
| 2 | Комикс (`comic`) | Рисованные панели и реплики в облачках. |
| 3 | Живой герой в сцене (`talk`) | Герой говорит в такт озвучке и действует среди предметов. Кадр заполняет рисованная локация, в которой тоже есть движение. |

Для форматов 1 и 2 можно задать три PNG одного героя с разными формами рта. Для формата 3 дайте агенту референс своего героя и сюжет. Он подготовит полноэкранный кадр и действие для каждой сцены, оживит кадры от озвучки через LTX и соберёт монтаж с музыкой и субтитрами.

Готовые примеры собираются на Windows и macOS с базовыми зависимостями. Для создания новых анимированных сцен в формате 3 настройте ComfyUI и LTX. Можно также загрузить свои анимированные клипы для монтажа. Команды запуска есть в [START.txt](START.txt), требования к генерации в [SETUP.txt](SETUP.txt), параметры героя, голоса и музыки в [TOOLS.txt](TOOLS.txt).
