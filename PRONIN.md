# Ролик через Pronin MCP

Используйте этот маршрут, когда для ролика нужны сцены и анимация из библиотеки Pronin. Движок работает в отдельной папке, а сценарий и озвучку можно подготовить в Reel Studio.

## Подключение

Подключите `https://proninlearn.ru/mcp` как MCP-сервер Pronin в Codex или Claude Code и войдите через личный аккаунт. В Codex CLI добавить сервер можно так.

```sh
codex mcp add pronin --url https://proninlearn.ru/mcp
codex mcp login pronin
```

Попросите агента вызвать `pronin_workspace_guide` перед установкой или запуском и следовать актуальным инструкциям. Для движка нужен Node.js 24+. Используйте личный доступ к движку и библиотеке. Храните их в папке Pronin, вне репозитория Reel Studio.

## Озвучка из Reel Studio

Подготовьте один WAV всей речи. Возьмите готовую запись или сгенерируйте её в Voicebox с выбранным голосом. Создайте в Pronin проект и план с тем же текстом. Для таймингов используйте среду Python с зависимостями из `requirements-captions.txt`.

```sh
python media_tools.py captions narration.wav pronin-words.json --language ru --format pronin
```

Прослушайте WAV и сверьте распознанные слова, особенно цифры и начало каждой сцены. При изменении или ускорении WAV снимите тайминги заново. Из папки движка Pronin импортируйте эту же дорожку и файл её таймингов.

```sh
npm run workflow -- import-voice "<папка проекта>" --track "<путь к narration.wav>" --words "<путь к pronin-words.json>"
```

Продолжите сцены, анимацию и экспорт по руководствам этапов в Pronin MCP. Готовый MP4 можно использовать целиком или указать как клип в сцене Reel Studio для дальнейшего монтажа. Для клипа с готовой речью и музыкой оставьте поле `music` пустым и используйте `audioMix: "legacy"` в `project.json`, чтобы сохранить этот баланс.
