# Reel Studio

Локальная сборка вертикальных роликов в Codex или Claude Code. Откройте папку как проект. Агент напишет сценарий, подберёт графику и соберёт ролик. MP4 и редактируемый проект появятся в output/.

## Установка

Скопируйте текст из [ПРОМПТ-УСТАНОВКИ.txt](ПРОМПТ-УСТАНОВКИ.txt) в Codex или Claude Code. Агент скачает проект из [открытого репозитория](https://github.com/maratch01-debug/reel-studio-student), установит зависимости и соберёт учебные ролики. Вход в GitHub не нужен.

Для самостоятельного запуска клонируйте репозиторий, перейдите в папку и запустите установщик.

    git clone https://github.com/maratch01-debug/reel-studio-student.git
    cd reel-studio-student

**Windows, PowerShell**

    powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Demo

**macOS, Терминал**

    sh install.sh --demo

На Windows для отсутствующих инструментов используется WinGet, на macOS — [Homebrew](https://brew.sh/). Добавьте -Voicebox на Windows или --voicebox на macOS, чтобы скачать и открыть официальный установщик Voicebox с проверкой SHA-256. Запустите приложение для озвучки новых сценариев. Готовый WAV можно использовать сразу.

Установщик сохраняет учебные MP4 в папках форматов внутри `2d-output/`. Рядом с каждым роликом лежит монтажный проект `project.json`.

Если Reel Studio уже установлена, обновите свой клон командой `git pull --ff-only` и повторно запустите установщик. Для новых демо используйте отдельную папку. На Windows используйте `.\studio.cmd quickstart --output-dir 2d-output-v2`, на macOS используйте `sh studio.sh quickstart --output-dir 2d-output-v2`.

## Первый ролик

> Сделай рилс в формате «Классика» с Тигрицей про прокат настольных игр. Собери тройной хук, меняй картинки и инфографику по смыслу реплик, возьми музыку из шаблона. Сохрани MP4 и монтажный проект.

## Голос и звук

У Пантеры, Тигрицы и Волка свои русские синтетические голоса. Reel Studio автоматически добавляет нужный профиль в локальный Voicebox при первой озвучке. Можно подставить свой WAV или выбрать уже созданный профиль. Пробы голосов лежат в `assets/voices/`. Команды для озвучки и импорта есть в [SETUP.txt](SETUP.txt).

Remotion монтирует кадры и титры. FFmpeg сводит речь и музыку примерно до −14 LUFS. В «Классике» звучит исходная дорожка классического Енота. Для остальных форматов есть инструментал на 90 BPM с приглушением во время речи. Дорожку можно заменить своей или выключить.

## Форматы

| № | Формат | Подача |
| --- | --- | --- |
| 1 | Классика (`classic`) | Белый фон с дымом, тройной хук, смена иллюстраций, инфографика и короткие синхронные титры. |
| 2 | Белый фон (`white-background`) | Чистый белый фон, говорящий герой, иллюстрации и короткие подписи. |
| 3 | Комикс (`comic`) | Рисованные панели и реплики в облачках. |
| 4 | Живой герой в сцене (`talk`) | Герой говорит в такт озвучке и действует среди предметов. Кадр заполняет рисованная локация, в которой тоже есть движение. |

Для «Классики», белого фона и комикса можно задать три PNG одного героя с разными формами рта. Для формата «Живой герой» дайте агенту референс своего героя и сюжет. Он подготовит полноэкранный кадр и действие для каждой сцены, оживит кадры от озвучки через LTX и соберёт монтаж с музыкой и субтитрами.

Готовые примеры собираются на Windows и macOS с базовыми зависимостями. Для создания новых анимированных сцен в формате «Живой герой» настройте ComfyUI и LTX. Можно также загрузить свои анимированные клипы для монтажа. Команды запуска есть в [START.txt](START.txt), требования к генерации в [SETUP.txt](SETUP.txt), параметры героя, голоса и музыки в [TOOLS.txt](TOOLS.txt).

## Reel Studio MCP

Локальный MCP входит в эту же сборку. Установщик ставит его зависимости. Откройте корень проекта в новом чате Codex или Claude Code. Агент сможет проверить установку, выбрать голос, собрать ролик из плана и экспортировать MP4. Подключение и проверка описаны в [MCP.md](MCP.md).
