Установи Reel Studio из открытого репозитория
https://github.com/maratch01-debug/reel-studio-student
и собери три учебных ролика. Первым покажи «Классику» с Тигрицей.

Клонируй этот репозиторий через Git в мою рабочую папку. Если он уже
установлен, обнови текущий клон через git pull --ff-only. Если обновление
мешает локальным правкам, используй свежий клон в соседней папке.
Вход в GitHub не нужен.

Из папки проекта прочитай START.txt, SETUP.txt и AGENTS.md. Определи мою
систему и запусти установщик с демо. На Windows выполни
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Demo
На macOS выполни
sh install.sh --demo

Установщик соберёт по одному вертикальному MP4 в таком порядке.
1. Говорящая голова, «Классика» с Тигрицей.
2. Комикс.
3. Живой герой в рисованной сцене, с речью, жестами и движением предметов.

Дождись завершения сборки. Проверь все три MP4 в 2d-output: файлы
открываются, есть звук, размер кадра 1080 × 1920. Дай отдельные
ссылки на «Классику», остальные MP4 и на project.json рядом с каждым роликом.

Покажи ссылки на файлы прямо в текущем чате. Для готового ролика с
указанным персонажем бери его стандартный голос, если я не выбрала другой.
Если MCP ещё не загрузился в текущем чате, используй команды studio.py
и закончи сборку. MCP.md понадобится для подключения в новом чате.
