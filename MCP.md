# Reel Studio MCP

Сервер запускается на компьютере из той же папки, где хранятся проекты. Он использует инструменты Reel Studio и не требует отдельного подключения к Pronin.

## Подключить в проекте

Запустите обычный установщик Reel Studio. Он ставит зависимости сервера вместе с Remotion и создаёт настройки подключения в этой копии проекта. Если обновляете уже установленный клон, сначала выполните `git pull --ff-only`.

Откройте **корень папки Reel Studio** в новом чате:

- В Codex сервер загружается из `.codex/config.toml` для доверенного проекта. Подтвердите доверие к этой папке, если Codex об этом спросит. [Документация Codex](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)
- В Claude Code сервер загружается из `.mcp.json`. Подтвердите подключение `reel-studio` при первом запуске. [Документация Claude Code](https://code.claude.com/docs/en/mcp#project-scope)

Попросите агента вызвать `reel_studio_doctor`. Если сервер не появился, проверьте, что открыт корень репозитория и Node.js 22+ доступен из приложения. Запустите установщик снова и откройте новый чат.

## Сделать ролик

> Через Reel Studio MCP собери «Классику» с Тигрицей про прокат настольных игр. Сделай тройной хук, меняй иллюстрации по репликам и оставь музыку шаблона. Сохрани MP4 и монтажный проект.

Шаблон и пример монтажа описаны в [CLASSIC.md](CLASSIC.md). Агент составит сценарий, сохранит `brief.json` в проекте и вызовет сборку. Результат появится в `output/reels/`, учебные ролики в `output/mcp-demos/`. Аудио и проекты остаются в локальной папке.

| Инструмент | Что делает |
| --- | --- |
| `reel_studio_catalog` | Показывает форматы, голоса и пример плана |
| `reel_studio_doctor` | Проверяет базовые инструменты и доступность локальных сервисов |
| `reel_studio_demo` | Собирает выбранные форматы с комплектными сценами и озвучкой |
| `reel_studio_voice` | Генерирует WAV комплектным голосом через Voicebox |
| `reel_studio_captions` | Снимает тайминги субтитров через Faster Whisper |
| `reel_studio_produce` | Собирает MP4 и монтажный проект из `brief.json` |
| `reel_studio_render` | Экспортирует правки из `project.json` в новый MP4 |
| `reel_studio_verify` | Проверяет параметры и декодирование MP4 |

Для демо используются комплектные файлы. Для новых роликов Voicebox нужен при генерации речи, ComfyUI при генерации изображений или анимации LTX, Faster Whisper при автоматических субтитрах. Готовые WAV, картинки и клипы можно использовать сразу. Установка локальных движков описана в [SETUP.txt](SETUP.txt).
