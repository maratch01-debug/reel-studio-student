Для первого запуска передайте агенту текст из ПРОМПТ-УСТАНОВКИ.txt.
Он клонирует репозиторий и запустит установщик из его папки.

1. Базовые инструменты
   Windows: powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Demo
   macOS: sh install.sh --demo
   Скрипты ставят базовые зависимости и собирают по одному учебному
   ролику в каждом из трёх форматов.
   Для установщика Voicebox добавьте -Voicebox на Windows или --voicebox
   на macOS. Манифест установщиков и ревизий — dependencies.json.

   Windows: Python 3.10+, Node.js 22+ с npm и FFmpeg. Если их нет, используйте
   winget (Python.Python.3.12, OpenJS.NodeJS.LTS и Gyan.FFmpeg) или
   официальные установщики.
   macOS: при установленном Homebrew можно поставить их командой
   brew install python node ffmpeg. Перезапустите терминал после установки.
   Из папки проекта запустите .\studio.cmd quickstart на Windows или
   sh studio.sh quickstart на macOS. Команда установит npm-зависимости
   Remotion и соберёт тестовые ролики. Порядок работы — в START.txt.
   FFmpeg должен поддерживать libx264 и AAC. Для рендера установщик
   использует установленный Chrome или Edge. При их отсутствии Remotion
   скачивает Chrome Headless Shell.
   Исходники композиции хранятся в репозитории. Пакеты устанавливаются из npm
   по package-lock.json. Лицензия: https://www.remotion.dev/docs/license

2. Дополнительно: локальная озвучка
   Скачайте Voicebox для своей системы с https://voicebox.sh/download
   и запустите приложение. Для Windows с NVIDIA используйте настройку CUDA
   внутри Voicebox, если она доступна. На Apple Silicon следуйте инструкции
   Voicebox для MLX и выберите поддерживаемый голосовой движок.
   Создайте собственный профиль и запишите короткую пробу. Если используется
   локальный API, адрес по умолчанию http://127.0.0.1:17493, схема на /docs.
   При produce агент может выбрать один из встроенных пресетов Qwen,
   использовать ваш локальный профиль или взять готовый аудиофайл.
   Первый запуск нового движка Voicebox может загрузить его веса. Проверьте
   свободное место и размер модели во вкладке Models. Qwen CustomVoice:
   https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice
   python provision.py profiles
   python provision.py speak --profile ID --text "Привет. Это мой первый ролик." intro.wav
   На macOS используйте python3. Другой поддерживаемый движок задаётся
   через --engine. Если API отличается, экспортируйте WAV из Voicebox.

3. Генерация живых сцен для формата 3
   Для новых сцен talk используется ComfyUI с LTX 2.3. В шаблоне
   портрет героя уже находится внутри полноэкранной рисованной сцены.
   Готовый учебный клип и примеры первых двух форматов собираются
   с базовыми зависимостями из раздела 1.
   Установите ComfyUI по https://docs.comfy.org/installation/manual_install
   Для Windows выберите подходящий GPU-бэкенд, для Apple Silicon — MPS.
   Держите сервер на localhost, обычно порт 8188. Укажите рабочий корень
   ComfyUI, в котором находятся папки input и output. Если сервер настроен
   на внешние папки входа или выхода, текущий адаптер их не поддерживает.
   python provision.py models --comfy "<корень ComfyUI>"
   Команда показывает наличие файлов и объём загрузки. Для скачивания
   добавьте --download. В наборе 42,33 ГБ весов. Команда докачивает
   незавершённые файлы и проверяет SHA-256 перед установкой.
   После загрузки обновите список моделей или перезапустите ComfyUI.
   Документация: https://docs.comfy.org/tutorials/video/ltx/ltx-2-3

4. Дополнительные инструменты
   Для анимированных схем и цифр дополнительные модели не требуются.
   Для локального создания иллюстраций установите ComfyUI-GGUF
   по https://github.com/city96/ComfyUI-GGUF и перезапустите ComfyUI.
   Затем проверьте набор весов: python provision.py models --set image
   --comfy "<корень ComfyUI>". Добавьте --download для скачивания.
   Для обеих групп весов используйте --set all.
   Автосубтитры, вырезание фона, интерполяция, иконки, графика и монтаж
   описаны в TOOLS.txt. Для первого ролика по графическому шаблону
   достаточно Python, Node.js, FFmpeg и зависимостей Remotion.

5. Проверка
   Откройте результат quickstart. Для своего 2D-героя убедитесь, что PNG
   выдерживают одинаковую позу при смене рта, подписи не обрезаются,
   звук слышен. Команды для macOS есть, тест выполнен на Windows.
   Для отдельного продвинутого режима LTX на Mac нужна своя проверка весов
   и памяти.
